## 🧠 Модели распознавания речи (STT Layer)

По умолчанию в проекте используется оптимизированная локальная модель **NVIDIA Parakeet V3 / Faster-Whisper (базовая модель с int8-квантованием)**.

### Почему эта модель выбрана по умолчанию:
- **Размер:** всего ~450 МБ.
- **Работает на любом железе:** превосходно и быстро работает на старых процессорах без поддержки современных инструкций (AVX-512) и **не требует дискретной видеокарты (GPU)**.
- **Мультиязычность:** поддерживает до 25 европейских языков, включая идеальное распознавание русского и английского языков.
- **100% приватность:** звук обрабатывается локально на устройстве без отправки в интернет.

## ⚙️ Настройка и смена моделей в `config.env`

Все параметры настраиваются в файле `config.env`.

### 1. Смена локальной модели (`STT_PROVIDER="local"`)
Если у вас мощный или наоборот очень слабый процессор, вы можете изменить размер модели:
```ini
STT_PROVIDER="local"
STT_LOCAL_MODEL="base" # Доступные варианты: "tiny" (самая быстрая), "base" (по умолчанию), "small", "medium"
STT_LANGUAGE="ru"      # "ru", "en" или "auto" (автоопределение)
```

---

### 2. Подключение внешних моделей по API (Cloud STT)

Если вы хотите использовать максимальное качество транскрибации или специализированные облачные API:

#### ⚡ Вариант A: Groq (Ультрабыстрый Whisper Turbo — 200x realtime)
1. Получите бесплатный ключ на [console.groq.com](https://console.groq.com).
2. В `config.env` укажите:
```ini
STT_PROVIDER="groq"
GROQ_API_KEY="gsk_ваш_ключ_здесь"
```

#### 🌐 Вариант B: OpenAI (Официальный Whisper API)
1. Получите ключ на [platform.openai.com](https://platform.openai.com).
2. В `config.env` укажите:
```ini
STT_PROVIDER="openai"
OPENAI_API_KEY="sk-proj-ваш_ключ_здесь"
```

#### 🔀 Вариант C: OpenRouter / Google Gemini / Mistral / Кастомные эндпоинты
Для любых OpenAI-совместимых аудио/транскрипционных шлюзов (включая OpenRouter, LocalAI, vLLM, Ollama Audio):
```ini
STT_PROVIDER="custom"
CUSTOM_STT_URL="https://openrouter.ai/api/v1/audio/transcriptions"
CUSTOM_STT_API_KEY="sk-or-ваш_ключ"
CUSTOM_STT_MODEL="openai/whisper-large-v3"
```

> **Примечание:** Если пропадет интернет или облачный API вернет ошибку, VibeBar автоматически переключится на встроенную локальную модель (**Safe Fallback**), и ваша запись не пропадет.

## 🌟 Ключевые возможности

1. **🎙️ Голосовой ввод в одно нажатие (Toggle Record)**:
   - Быстрая запись голоса на горячую клавишу (`vibebar-record.sh` или `vibebar-record`).
   - Нажмите хоткей один раз для старта записи, нажмите второй раз для завершения и моментальной обработки.
2. **🏷️ Умная классификация текста (методология Маргулана)**:
   - 💡 **Идеи**: фразы, начинающиеся со слов `идея`, `мысль`, `заметка` (сохраняются отдельно, клик в трее копирует).
   - ❗ **Напоминания**: фразы `не забыть`, `напомнить`, `важно` (сохраняются как чекбоксы `[ ]` прямо в Markdown).
   - ⏸ **Паузы**: `перерыв`, `пауза`, `стоп`, `обед` (останавливают счетчик активного времени).
   - ⏱ **Задачи**: любой другой текст становится активной задачей с живым таймером.
3. **📊 Живой таймер в системном трее (`AyatanaAppIndicator3`)**:
   - Показывает текущую задачу и время ее выполнения: `[Разработка VibeBar] (0:45)`.
4. **📋 Умный менеджер буфера обмена**:
   - Автоматическое сохранение истории 15 последних элементов без нагрузки на процессор.
   - Автоочистка строк шелла и терминала (`user@host:~$`).
   - Моментальная автовставка кликом из меню через `xdotool`.
5. **📝 Аналитика и экспорт в Obsidian**:
   - Расчет продуктивного времени за день и за неделю с отсечением пауз и ночных пропусков.
   - Автоматический экспорт сводки в Obsidian Vault.

## ⌨️ Настройка горячей клавиши в Linux Mint (Cinnamon)

1. Откройте **Параметры системы** ➔ **Клавиатура** ➔ вкладку **Комбинации клавиш**.
2. В левой колонке выберите **Дополнительные комбинации** (Custom Shortcuts) и нажмите **Добавить**.
3. Заполните поля:
   - **Название:** `VibeBar Record`
   - **Команда:** `vibebar-record` (или путь к `bin/vibebar-record.sh`)
4. Назначьте удобную клавишу (например, **F9** или `Ctrl+Alt+V`).
