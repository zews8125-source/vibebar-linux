## 🌟 Ключевые возможности

1. **🎙️ Голосовой ввод в одно нажатие (Toggle Record)**:
   - Быстрая запись голоса на горячую клавишу (`vibebar-record.sh` или `vibebar-record`).
   - Нажмите хоткей один раз для старта записи, нажмите второй раз для завершения и моментальной обработки.
2. **🧠 Гибридный STT-движок (Локальный + Облачный)**:
   - **Локальный (по умолчанию)**: `faster-whisper` (int8) / NVIDIA Parakeet ONNX — сверхбыстрое распознавание даже на старых процессорах без видеокарты и без интернета.
   - **Облачный (API)**: Поддержка **Groq Whisper Turbo** (200-300x realtime), **OpenAI Whisper** и кастомных OpenAI-совместимых серверов.
3. **🏷️ Умная классификация текста (методология Маргулана)**:
   - 💡 **Идеи**: фразы, начинающиеся со слов `идея`, `мысль`, `заметка` (сохраняются отдельно, клик в трее копирует).
   - ❗ **Напоминания**: фразы `не забыть`, `напомнить`, `важно` (сохраняются как чекбоксы `[ ]` прямо в Markdown).
   - ⏸ **Паузы**: `перерыв`, `пауза`, `стоп`, `обед` (останавливают счетчик активного времени).
   - ⏱ **Задачи**: любой другой текст становится активной задачей с живым таймером.
4. **📊 Живой таймер в системном трее (`AyatanaAppIndicator3`)**:
   - Показывает текущую задачу и время ее выполнения: `[Разработка VibeBar] (0:45)`.
5. **📋 Умный менеджер буфера обмена**:
   - Автоматическое сохранение истории 15 последних элементов без нагрузки на процессор.
   - Автоочистка строк шелла и терминала (`user@host:~$`).
   - Моментальная автовставка кликом из меню через `xdotool`.
6. **📝 Аналитика и экспорт в Obsidian**:
   - Расчет продуктивного времени за день и за неделю с отсечением пауз и ночных пропусков.
   - Автоматический экспорт сводки в Obsidian Vault.

## 🚀 Установка

### Вариант 1: Быстрый запуск в текущей папке
```bash
./install.sh
./start.sh
```

### Вариант 2: Общесистемная установка на любой ПК
Подробности в [dist-installer/README.md](dist-installer/README.md):
```bash
cd dist-installer
sudo ./install.sh
```

## ⌨️ Настройка горячей клавиши в Linux Mint (Cinnamon)

1. Откройте **Параметры системы** ➔ **Клавиатура** ➔ вкладку **Комбинации клавиш**.
2. В левой колонке выберите **Дополнительные комбинации** (Custom Shortcuts) и нажмите **Добавить**.
3. Заполните поля:
   - **Название:** `VibeBar Record`
   - **Команда:** `vibebar-record` (или путь к `bin/vibebar-record.sh`)
4. Назначьте удобную клавишу (например, **F9** или `Ctrl+Alt+V`).

## ⚙️ Конфигурация (`config.env`)

```ini
# Выбор движка: local | groq | openai | custom
STT_PROVIDER="local"
STT_LOCAL_MODEL="base"
STT_LANGUAGE="ru"

# Ключи для облачного распознавания (опционально)
GROQ_API_KEY="gsk_..."
OPENAI_API_KEY="sk-..."

# Пути к файлам журнала и Obsidian
VIBEBAR_JOURNAL_FILE="~/vibebar-journal.md"
VIBEBAR_OBSIDIAN_VAULT_FILE="~/Documents/Obsidian/Daily/VibeBar.md"
```
